# LMS Answer Comments

This module integrates answer entities with the core Comment module,
allowing teachers to post comments on student answers when evaluating and
students to answer to those comments or add their own comments on their
answers.


## Installation

If the Comment module was not used on the project previously, Comment
module permissions to post, edit and view comments must be set.

Otherwise the module is fully functional without any additional config steps.


## Customization

The module installs a new "lms_answer_comment" comment type that can be 
customized in terms of fields and theming if needed.
