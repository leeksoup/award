# Developer's Guide for Drupal LMS

The Drupal LMS Developer's Guide gives developers working with the LMS module a detailed look at the module's architecture, entity structure, service layer, and API functionality. The guide covers setting up a development environment, extending core functionality, theming & frontend integration, and testing & deployment.

Whether you're contributing module code, or writing custom functions for a specific learning environment, this guide will help you understand and extend the Drupal LMS ecosystem.
