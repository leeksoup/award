# Course Creator's Guide for Drupal LMS

This guide is for site administrators and educators to create and manage learning experiences using the [Drupal LMS module](https://www.drupal.org/project/lms).  It covers installation, configuration, and operations, including:

-   course creation,
-   lesson management,
-   activity setup,
-   student enrolment, and
-   performance tracking.

You'll learn how different activity types (multiple choice, free text, true/false, etc.) are implemented, and best practices for course design and student engagement.

These instructions will help you create effective online learning with Drupal LMS, whether you're building a simple training or a complex educational platform.
