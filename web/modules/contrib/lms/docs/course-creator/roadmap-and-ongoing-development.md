# Roadmap and Ongoing Development

Drupal LMS is actively being developed. Here are some features planned for upcoming releases, or to be included in the Drupal LMS ecosystem:

## Upcoming Features

### H5P Integration

[H5P](https://h5p.org/) integration will let you use interactive HTML5 content in Drupal LMS activities:

-   Interactive videos with embedded questions
-   Drag-and-drop exercises
-   Flashcards and memory games
-   Interactive presentations
-   Timeline activities

This will add many more interactive learning activities.

### Video Conferencing Integration

Integrations with open-source video meeting tools will enable:

-   Live sessions within courses
-   Recording and playback of sessions
-   Attendance tracking
-   Virtual office hours
-   Group study sessions

### Calendar and Events

A calendar system will help organize learning activities:

-   Course schedules and deadlines
-   Class session planning
-   Assignment due dates
-   Automated reminders
-   Personal student calendars

### Course Discussion and Messaging

Better communication tools will include:

-   Activity-specific discussion
-   Direct messaging between students and teachers
-   Group messaging for classes
-   Notification system for updates and feedback

### Improved Analytics and Reporting

Additional reporting tools may include:

-   Learning analytics dashboard
-   Custom report building
-   Export options in multiple formats
-   Visual data displays

### Migration Tools

Tools to help move from other systems:

-   Opigno migration
-   Moodle content import
-   SCORM package support
-   LTI (Learning Tools Interoperability) compliance
-   Batch content creation tools

### LMS Base Theme

A contrib base theme for Drupal LMS is under development.  This theme will:

-   Integrate all of the LMS components
-   Provide a UI for controlling color variables
-   Provide a base for easy LMS customization
-   Likely include Tailwind and/or SASS variables

### UI/UX Improvements

There are a number of ways that Drupal LMS can be made easier and more intuitive to use and manage. There is an **[active issue](https://www.drupal.org/project/lms/issues/3525100)** on this topic, please add to the discussion!

## Community Contributions

As an open-source project, Drupal LMS welcomes community help:

-   Additional activity type plugins
-   Theme improvements
-   Integration with other Drupal modules
-   Sub-module development
-   Documentation improvements
-   Translations

## Staying Updated

To stay informed about Drupal LMS development:

-   Follow the [GitHub repository](https://github.com/graber-1/drupal_lms_ddev)
-   Join the Drupal LMS [Slack](https://www.drupal.org/community/contributor-guide/reference-information/talk/tools/slack) channel: #lms
-   Discuss issues in the [issue queue](https://www.drupal.org/project/issues/lms?categories=All)
-   Participate in testing new features

You're very welcome to join the community channels — your participation allows you to provide feedback and influence the direction of future development.

## Feature Requests and Feedback

Your input helps prioritize development:

-   Submit feature requests and bug reports through the [issue queue](https://www.drupal.org/project/issues/lms?categories=All)
-   Provide feedback on existing features
-   Contribute or review documentation and code
-   Participate in user surveys
-   Share how you’re using Drupal LMS

By participating in the Drupal LMS community, you can help shape its future while creating your own custom learning environment.
